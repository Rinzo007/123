# wikiroutes

CLI-инструмент для загрузки, анализа и экспорта маршрутов общественного транспорта из WikiRoutes с GIS-расчётами, дедупликацией и дополнительными источниками данных.

## Требования

- Python 3.14
- `uv`
- Для Overture: дополнительные зависимости из extra `overture`

## Установка

```powershell
uv sync
```

Для Overture Maps:

```powershell
uv sync --extra overture
```

Для разработки:

```powershell
uv sync --extra dev --extra overture
```

## Запуск

```powershell
uv run wikiroutes --help
uv run wikiroutes voronezh --dedup
```

Также поддерживается модульный запуск:

```powershell
uv run python -m wikiroutes --help
```

## Пакетный режим

Загрузка команд из файла — по строке на запуск, все команды выполняются в одном процессе:

```powershell
uv run python -m wikiroutes --batch "D:\Programs\Города\Итоги.txt"
```

Правила разбора файла:

- пустые строки и строки вида `- Заголовок -` пропускаются (можно группировать команды по регионам);
- `#`-комментарии пропускаются (в т.ч. после ` #` в конце строки);
- префикс `python -m wikiroutes` / `wikiroutes` в начале строки необязателен;
- точные дубликаты команд выполняются один раз;
- ошибка одной команды не прерывает пакет — в конце выводится сводка;
- внутри файла `--batch` игнорируется (защита от рекурсии).

## Маршруты

Все типы маршрутов из каталога обрабатываются единообразно. Деления на базовые и вторичные маршруты больше нет: один и тот же набор фильтров применяется ко всему выбранному `--type`/`--no-type` набору, а bbox строится по загруженной сети целиком.

`--no-bbox-filter` оставлен как устаревший compatibility-аргумент; он больше не меняет состав сети.

## Дедупликация

Дедупликация работает по графу похожести направлений (`pairs` edge-list с метрикой `K2_max`):

1. `dedup.dedup_analyze` строит разрежённый список пар направлений, превышающих порог похожести;
2. `dedup_policy.dedup_compute_removals` итеративно выбирает жертву: среди участников активных пар — направление с минимальным объёмом застройки GHS (при равенстве — более сильная пара, затем меньший ID);
3. после каждого удаления активный набор направлений пересчитывается; направления удаляются по одному.

Плотная матрица K2 в памяти не строится — она материализуется только через `materialize_dedup_matrix()` при необходимости экспорта/отчёта.

Старый `--dedup-strategy` больше не является частью основного CLI/API. Для переходного периода старый аргумент распознаётся compatibility-слоем и выдаёт `DeprecationWarning`.

## Структура

Проект использует flat package layout: корень репозитория является пакетом `wikiroutes` (подпакеты — `wikiroutes.overture` и др., тесты — в `tests/`, внутренняя документация — в `docs/`).

## Важные ограничения

- Runtime-проверка Python 3.14 должна выполняться в CI/локальном окружении.
- Overture требует поддерживаемой версии `overturemaps` и актуального формата релиза.
- GIS-пайплайн чувствителен к версиям бинарных зависимостей (`numpy`, `rasterio`, `pyproj`, `shapely`).
