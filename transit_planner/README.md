# Transit Planner

Самостоятельное ядро для проектирования и моделирования общественного транспорта.

Модуль расположен в `transit_planner/` и намеренно не зависит от существующего расчётного кода репозитория.

## Реализовано

- доменные модели города и транспортной сети;
- остановки, маршруты, сервисы и виды транспорта;
- OD-спрос;
- JSON-сериализация сети;
- базовый расчёт провозной способности;
- дорожный граф с поддержкой односторонних участков;
- кратчайший путь по времени;
- dependency-free сеточный пространственный индекс;
- GeoJSON-провайдер дорожных сегментов;
- компонуемый фасад источников городских данных;
- FastAPI контракт;
- автоматические тесты и отдельный CI.

## Запуск

```powershell
cd transit_planner
python -m pytest -q
pip install -e ".[api,test]"
uvicorn transit_planner.api:app --reload
```
