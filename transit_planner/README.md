# Transit Planner

Самостоятельное ядро для проектирования и моделирования общественного транспорта.

Новая реализация создаётся непосредственно в этом репозитории, но изолирована в каталоге `transit_planner/`. Она не импортирует существующие модули проекта.

## Первый срез

- доменные модели города и транспортной сети;
- остановки, маршруты, виды транспорта, подвижной состав и интервалы;
- OD-спрос;
- валидация инвариантов;
- JSON-сериализация сети;
- расчёт базовой провозной способности;
- минимальный FastAPI-контракт;
- автоматические тесты.

## Запуск

```powershell
cd transit_planner
python -m pytest -q
pip install -e ".[api,test]"
uvicorn transit_planner.api:app --reload
```
