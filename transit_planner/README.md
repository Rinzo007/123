# Transit Planner

Самостоятельное ядро для проектирования и моделирования общественного транспорта.

Модуль расположен в transit_planner/ и не зависит от старого расчётного кода репозитория.

## Реализовано
- доменная модель города и транспортной сети;
- остановки, маршруты, сервисы и виды транспорта;
- OD-спрос;
- JSON-сериализация сети;
- базовый расчёт провозной способности;
- дорожный граф с односторонними участками;
- кратчайший путь по времени;
- dependency-free пространственный индекс;
- GeoJSON-провайдер дорог;
- OSM/Overpass-провайдер дорог и остановок;
- Overture Transportation GeoParquet-провайдер;
- сеточная генерация зон спроса;
- гравитационная генерация OD;
- привязка остановок к дорожному графу;
- мультимодальный маршрутизатор с пешими связями и ожиданием;
- логит-модель выбора вида транспорта;
- распределение OD по транспортной сети;
- пассажиропотоки по маршрутам и участкам;
- расчёт загрузки и итеративный штраф перегруженности;
- FastAPI контракт;
- автоматические тесты и отдельный CI.

## Запуск
```powershell
cd transit_planner
python -m pytest -q
pip install -e ".[api,test]"
uvicorn transit_planner.api:app --reload
```
